## ⭐ Featured Project

<div align="center">

### 🛍️ Shop.co: Full-Stack E-Commerce Platform

*A MERN storefront with a role-based admin dashboard, built well beyond a class assignment.*

[![Live Site](https://img.shields.io/badge/LIVE_SITE-00FFF0?style=for-the-badge&logo=vercel&logoColor=000)](https://shopco-premium.vercel.app)

</div>

| | |
|:---|:---|
| **🛒 Storefront** | Home, category pages with filters / sort / pagination, product detail, cart and checkout |
| **🔐 Auth** | JWT in httpOnly cookies, bcrypt password hashing, role-based access (user / admin) |
| **📊 Admin Dashboard** | Analytics charts, product CRUD with Cloudinary image upload, users table, orders table with payment and fulfillment status, printable receipts |
| **⚙️ Architecture** | Separate Vercel deployments for the React frontend and the Express API |

**Frontend:** `React 19` · `Vite` · `Tailwind CSS v4` · `React Router` · `Framer Motion` · `Zod` · `Recharts`
**Backend:** `Node.js` · `Express` · `MongoDB (Mongoose)` · `JWT` · `bcryptjs` · `Multer` · `Cloudinary`
